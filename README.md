# CyberArk PAM Notes

Beginner-friendly notes on CyberArk PAM: Vault, Safes, PVWA, CPM and PSM.

## What's inside

| File | Description |
|------|-------------|
| [PAM-basics.md](PAM-basics.md) | Core components, how they fit together, and a flow diagram |

## What you'll learn

- Why privileged accounts need special protection
- What the **Vault** is and how **Safes** control access through member permissions
- How users log in through **PVWA** (Password Vault Web Access)
- How the **Central Policy Manager (CPM)** rotates and verifies passwords automatically
- How the **Privileged Session Manager (PSM)** proxies and records privileged sessions
- Why this matters for SOC and IAM roles

## Scope

These are learning notes, not official documentation or a deployment guide. Details can change between CyberArk versions, so check the [official CyberArk documentation](https://docs.cyberark.com) for authoritative information.

Corrections are welcome. Please open an issue or pull request.
