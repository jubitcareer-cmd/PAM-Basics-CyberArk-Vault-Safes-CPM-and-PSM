# CyberArk PAM Notes

Beginner-friendly study notes on **Privileged Access Management (PAM)** using CyberArk: the Vault, Safes, CPM and PSM, explained in plain language with a diagram.

## What's inside

| File | Description |
|------|-------------|
| [PAM-basics.md](PAM-basics.md) | Core CyberArk components, how they fit together, and a simple flow diagram |

## What you'll learn

- Why privileged accounts need special protection
- What the **Vault** is and how it stores credentials
- How **Safes** control who can see which accounts
- How the **CPM** rotates and verifies passwords automatically
- How the **PSM** proxies and records privileged sessions
- Why all this matters for SOC and IAM roles

## Who is this for?

- Students and career changers moving into cybersecurity, SOC or IAM
- Anyone who wants a quick, plain-English overview of CyberArk concepts before diving into the official documentation

## Scope and honesty note

These are **learning notes**, not official documentation and not a production deployment guide. Product details can change between CyberArk versions, so check the [official CyberArk documentation](https://docs.cyberark.com) for authoritative information.
